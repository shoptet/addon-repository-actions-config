# Plans

Forward-looking scope for work in this repository. A plan describes what is *going* to be built; it
is never edited to describe what shipped. When a plan's reality changes, add a status banner.

Each initiative gets its own subfolder with a `README.md` that indexes its slices. Add new rows to
the table below when starting a new initiative.

| initiative | what | status |
| --- | --- | --- |
| [`rule-unification`](./rule-unification/README.md) | one rule set, two runners — shared npm packages for linting, consumed by this repo's gate and the `shoptet` CLI | not started |
